# Save Documentation

이 대화에서 논의된 주제/질문을 `claude_docs/` 디렉토리에 상세한 마크다운 파일로 저장합니다.

## 작업 순서

1. **대화 내용 분석**: 현재 대화에서 다룬 주제, 질문, 답변을 검토합니다.

2. **문서화할 주제 식별**: 주요 질문이나 학습 내용을 파악합니다. 여러 주제가 있다면 각각 별도 파일로 저장합니다.

3. **파일명 결정**: 주제를 영어로 표현한 snake_case 이름을 사용합니다 (예: `ppo_algorithm_overview.md`, `fsdp_sharding_explained.md`). 기존 파일과 중복되지 않도록 `claude_docs/` 디렉토리의 기존 파일 목록을 먼저 확인합니다.

4. **마크다운 파일 작성**: 아래 구조를 따릅니다:

```
---
date: <오늘 날짜 YYYY-MM-DD>
topic: <주제 한 줄 요약 (한국어 가능)>
tags: [<관련 태그들>]
---

# <주제 제목>

## 개요
<이 문서가 다루는 내용과 맥락>

## 핵심 내용
<대화에서 나온 중요한 설명, 코드, 개념들을 체계적으로 정리>

## 상세 설명
<심화 내용, 예시, 코드 스니펫 등>

## 관련 파일/코드
<verl 코드베이스에서 관련된 파일 경로나 함수명 (해당되는 경우)>

## 참고 사항
<주의할 점, 추가 참고사항, 관련 주제 링크>
```

5. **저장**: Write 도구를 사용해 `claude_docs/<파일명>.md`에 저장합니다.

6. **결과 보고**: 저장한 파일 목록과 각 파일의 주제를 간략히 알려줍니다.
