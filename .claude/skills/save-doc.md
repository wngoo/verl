현재 대화에서 주고받은 질의응답 내용을 분석하고, `claude_docs/` 디렉토리에 적절한 이름의 마크다운 파일로 저장한다.

### 1. 대화 내용 분석

현재 대화에서 다룬 주제를 파악한다:

- 어떤 문제나 개념을 다뤘는지 식별
- 핵심 질문과 답변 정리
- 코드, 설정, 파라미터 등 기술적 내용 추출

### 2. 기존 파일 확인

`claude_docs/` 디렉토리의 파일 목록을 확인한다:

- 동일하거나 유사한 주제를 다루는 파일이 이미 있는지 검사
- 있다면 새 파일 생성 대신 기존 파일에 내용을 추가하거나 업데이트하는 것을 고려
- 없다면 새 파일을 생성

### 3. 파일명 결정

파일명은 다음 규칙을 따른다:

- 영어 소문자 + 언더스코어 형식 (예: `vllm_memory_tuning.md`)
- 주제를 명확히 드러내는 이름
- 너무 길지 않게 (3~5단어 수준)
- 기존 파일명 패턴과 일관성 유지

### 4. 문서 작성

문서는 다음 구조로 작성한다:

- **제목**: 주제를 명확히 표현하는 한국어 제목
- **개요**: 이 문서가 다루는 내용을 1~2문장으로 요약
- **본문**: 질의응답 내용을 논리적으로 재구성 (단순 Q&A 나열이 아닌 체계적인 설명)
  - 개념 설명
  - 코드/설정 예시 (있다면)
  - 주의사항 또는 권장사항
- **참고 코드 위치**: 관련 파일 경로와 라인 번호 (확인된 경우)

문서 품질 기준:
- 나중에 이 문서만 읽어도 내용을 이해할 수 있도록 자기완결적으로 작성
- 대화 중 확인한 실제 코드/설정값 기반으로 작성 (추측 배제)
- 불필요한 반복이나 잡담 내용은 제외

### 5. 저장

Write 도구로 파일을 저장하고, 저장한 파일 경로를 사용자에게 알린다.
